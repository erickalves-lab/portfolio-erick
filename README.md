# Erick Alves — Portfólio

## Como visualizar
Abra `index.html` no navegador ou rode um servidor local.

Exemplo com Python:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Antes de publicar
Substitua em `index.html`:
- `SEUEMAIL`
- `SEULINK`
- `SEUNUMERO`
- `https://SEU-DOMINIO.com/`

Também pode trocar os visuais abstratos dos projetos por imagens reais quando quiser.
